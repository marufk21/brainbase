# Take-Home Assignment Package

This folder contains everything needed for the take-home assignment.

## Contents

| Item | Description |
|------|-------------|
| **Problem_Statement.docx** | Full problem statement and instructions. Give this to the candidate. |
| **sample-data/** | Fictional sample data the candidate can use. |

## How to use

1. Send the candidate the `Problem_Statement.docx` file (or its content).
2. Also share the entire `sample-data` folder (or the whole package).
3. Candidate must reply and acknowledge the email before the 72-hour clock starts.
4. Candidate creates a **separate new repository** for their solution.

## Important reminders for us

- Sample data is completely fictional. Candidates are told not to treat it as real.
- We only provide Gemini credits if requested.
- Evaluation focus: thinking quality, data modeling & relationships, architecture, code quality, ability to break/improve the system.
